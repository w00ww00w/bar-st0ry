# Второй мозг: BarStory

Короткий вход в проект для человека и AI. Сначала прочитайте этот файл, затем переходите только к узлам графа, связанным с задачей.

## Продукт

BarStory — мобильная городская игра. Пользователь выбирает бар на карте, посещает его и отмечает визит. Текущий MVP хранит прогресс локально на устройстве.

## Где что находится

- `app/page.tsx` — экран карты, тестовые бары и логика отметки визита.
- `app/globals.css` — визуальный язык и адаптация под телефон.
- `app/layout.tsx` — язык и метаданные сайта.
- `docs/brain/graph.md` — граф файлов, данных и функций.
- `docs/brain/decisions.md` — только долгоживущие архитектурные решения.
- `scripts/brain.ps1` — запуск локального графа `codebase-memory-mcp` с UI.
- `scripts/import-bars.mjs` — импорт баров Новосибирска из OpenStreetMap.
- `data/bars.json` — генерируемый каталог баров после импорта.

## Автоматический граф

`scripts/brain.ps1` запускает локальный индекс функций, вызовов и файлов. UI открывается на `http://localhost:9749`.

## Контракты MVP

- Ключ прогресса: `bar-map.visited`.
- Значение: JSON-массив строковых OSM-идентификаторов баров.
- Повторное нажатие отменяет визит.
- Интерфейс обязан работать с клавиатурой, касанием и узким экраном.

## Следующий продуктовый шаг

Получить от владельца город и источник реального списка баров. Затем заменить декоративную карту настоящей картой и вынести `bars` в отдельный источник данных, не меняя контракт прогресса.
