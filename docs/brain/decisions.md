# Архитектурные решения

## 2026-08-19 — Web-first MVP

Начинаем с адаптивного сайта и локального прогресса. Это позволяет проверить игровую механику без аккаунтов и сервера. При переходе к iOS интерфейс можно обернуть в Capacitor; правила прогресса и данные следует держать независимыми от React-компонентов.

## 2026-08-19 — Документация как навигационный граф

«Второй мозг» хранится рядом с кодом в Markdown и Mermaid. Он версионируется вместе с проектом, открывается без специального сервиса и содержит только навигацию, контракты и долговечные решения.

## 2026-08-19 — Автоматический граф кода

`codebase-memory-mcp` используется в UI-варианте. Автоматический локальный индекс отвечает за изменчивые связи файлов, функций и вызовов; Markdown остаётся источником продуктовых контрактов и причин решений.

## 2026-08-19 — Источник каталога баров

Первичный каталог Новосибирска импортируется из OpenStreetMap через Overpass API и хранит атрибуцию OSM. Редакционные описания и проверка заведений остаются собственными данными проекта.
